# Frozen-artifact space interpretation study

Question: how much of the 36-candidate TRELLIS cohort's failure is recoverable by interpreting unchanged geometry? Zero GPU jobs, no source edits, floor patches, decimation, gameplay, intent UX or renderer changes. Preserve both previous frozen studies. Runtime branch codex/generated-space-interpretation; integration receives docs/evidence only.

Freeze algorithms on synthetic geometry tests before evaluating this cohort. This is a retrospective exploratory study, not a new generation sample or a blind generalization claim. Original labels/categories/seed/IDs and prior reports must not enter scale selection. The selector takes only original triangle geometry and the predeclared physical-scale set [6,10,12,16], produces geometry-derived features/rankings and exactly one scale, and cannot read files or call route acceptance. Persist all 36 selections before running any outcome evaluation. Do not revise the selector in response to cohort results. Absolute physical scale is unidentifiable without a known-size reference; measure usable-scale accuracy (selected scale passes independent criteria), opportunity capture (selected pass / any tested scale pass), and loss against that bounded reference, not exact-metres accuracy.

Derive topology criteria only from original intent text/semantic envelope, never cohort category/ID or outcome. Enclosed passages, open courtyard regions, through-doorway apertures, elevated bridge decks and broad covered interiors must have explicit distinct witnesses; do not merely remove enclosure and accept any roof. Body radius .3, height1.8, eye1.65, step.25, slope35, original support/collision and reversible >=3m traversal remain. No authored destination support. Exterior scaffolding may connect only outside source geometry; entry/search may not teleport through walls or fill holes. Freeze these rules before cohort evaluation and report unsupported/ambiguous intents honestly.

Measurements: corrected prior fixed6 strict endpoint; artifact-only automatic scale with old strict search; intent criteria with legacy entry/search at chosen scale; intent criteria plus expanded entry/component/route search at chosen scale. Independently evaluate the full four-scale set under the new criteria to measure bounded available opportunity; these labels are computed only after selections are frozen and never feed selection. Actual browser verification for each eligible chosen-scale final result; no automatic switch to another scale after failure. Retain every failure and intermediate ablation. Report category counts, selection metrics with denominators, search/resource bounds, source hashes, per-route support/topology witnesses, and interpretation vs generation attribution with uncertainty. A failed bounded search is not proof of irreparable generation.

Pinned implementation seams (prototype-local): scale.ts exports PHYSICAL_SCALES and selectPhysicalScale(mesh, scales?) returning selectedScale and per-scale features/ranking; no I/O, text, IDs, labels or route imports. criteria.ts exports deriveSpatialCriteria(rawIntent, semantics?) and SpatialCriteria. routes.ts exports assessInterpretedSpace({mesh,transform,criteria,searchMode:'legacy'|'expanded'}) returning an extended PassageAssessment with criteria/witness/search diagnostics. Existing passage assessor/navigator/rendering files remain unchanged after adopting the separately verified numerical fix. Shared production protocol/config unchanged. Lead owns dataset preparation, evaluation, browser, report and integration. Agents own separate scale and criteria/routes modules; independent reviewer audits methodology and evidence.

## Retained post-hoc correction and completed measurements

The initial phase remains frozen and separately reported. After the first 11 results exposed roof/open-sky compilation errors and a non-superset expanded entry search, a second method freeze added only `deriveCorrectedSpatialCriteria(rawIntent, semantics?)` in criteria-v2.ts and deterministic expanded→legacy fallback at the same already-selected scale. No selector, selected scale, geometry, physical player, witness or search cap changed. Corrected data lives in `.runtime/interpretation-replay`. Full transform, criteria, source and method hashes gate cached assessment reuse. The four-scale reference uses the identical fallback policy. This is explicitly post-hoc, not blind validation.

Primary browser acceptance uses the first complete attempt. One unexplained cave return stop is retained as a failure; a byte-identical separately identified repeat establishes later traversability without replacing that record. Generic old-criterion scale controls and nonselected-scale references have separate case IDs and never enter the primary numerator. A real inspection API restart verifies every case identity, asset hash and visit journal.

Final report: docs/research/generated-space-interpretation.md. Generic same-criterion scale recovery is 12→21 of36; all21 browser controls pass.
