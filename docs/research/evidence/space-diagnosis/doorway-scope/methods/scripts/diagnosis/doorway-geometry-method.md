# Scoped doorway route consumption

This separate route module composes the doorway criteria wrapper with the frozen coverage predecessor from commit `e79e3fc`. Method and synthetic tests are frozen before any scoped cohort assessment. No original compiler, entry/coverage evaluator, navigator, source mesh or physical dimension changes.

For criteria without a doorway override, delegate directly to the frozen coverage module. Preserve its result and trace exactly, apart from incidental timings inherent to repeated calls.

For scoped criteria, **never call an unmodified predecessor using the smaller global width**: its existing aperture predicate does not understand widthByTopology. First run the complete same-mode coverage predecessor with conservative global width equal to the maximum of global width and doorway override. This is 2.4 for the scoped compiler's output. Omit widthByTopology from that predecessor input so its criteria are exactly the pre-scope width obligations. A predecessor success already satisfies the stronger obligations and preserves that route and witnesses. Return the actual scoped criteria with explicit conservative-witness provenance in the outer trace.

Only on predecessor failure run one copied fair-coverage core with scoped global width and an aperture minimum equal to the maximum of global and doorway-specific width. Preserve all bounded scheduling, exact original prism entry tests, physical movement and topology predicates. The only witness change is the aperture-width comparison and its recorded threshold; successful aperture measurements also declare the consumed threshold. Unknown/non-finite or physically invalid doorway override inputs fail explicitly rather than letting NaN bypass comparison.

The scoped core must still prove every required topology, covered portion, original support, body clearance, original roof/flank rays, opposite crossing sides, wider spaces on both sides of the aperture, >=3m route and reversible exterior seam. A 0.6 global field cannot admit a 1.4m aperture when the local requirement remains 2.4.

Trace scopePass distinguishes conservative-predecessor from scoped-coverage without discarding predecessor pass fields. Per-pass start and complete events include the actual criteria used, status and diagnostics. The outer selected result records returned scoped criteria and which pass supplied the witness. Returned counters describe the selected/last pass as in the predecessor; complete multi-pass costs remain in traces. No-override inputs add no new trace wrapper.

Synthetic geometry tests cover a 2.6 m original aperture with local broad floor but narrower supported route; a 1.4 m aperture that would falsely pass if the override were ignored; complete preservation of a predecessor successful route; exact no-override parity; sealed aperture, absent roof, disconnected floor and independently broad chamber negatives. Successful fixtures are walked from exterior approach through the generated route and back with the unchanged navigator; dense support IDs must all refer to original triangles. Both expanded and legacy search modes require scoped threshold enforcement.

This fixture validates the intended scope rule, not any frozen-cohort rescue. Existing limitations—axis-aligned witness rays, bounded search, support discretization and finite lexical interpretation—remain. The lead freezes the composed phase with its source dependencies before any cohort replay; selected scales and all historical attempts stay fixed.

## Disclosed inherited seam precision limitation

The synthetic fixtures use transform position `[0,0,0.1]`; no physical dimensions differ from the origin fixture. During development the same 2.6 m-aperture fixture at `[0,0,0]` produced valid topology witnesses but exhausted eight scoped approach builds. Proposal `58:2` started at `[1.4,1.65,-4.4]` and targeted `[1.4,1.65,-0.8]`: the forward start assessment failed unsupported-footprint after seven of nine authored support samples, whereas the reverse movement reached Z `-4.399999999999992` successfully. The +0.1, +0.2 and +0.3 Z translations passed. This is evidence of an inherited approach-boundary numerical issue, reported to the lead; it is not fixed or hidden by a tolerance change in this scope phase. The fixture translation isolates scope-consumption tests, and these tests do not establish translation-invariant navigation. Historical failures remain failures.

At most four separately bounded evaluator passes run per scoped search mode: the conservative coverage predecessor can invoke baseline, prism and fair coverage; only after failure does one scoped fair pass run. No-scope inputs retain the predecessor's three-pass maximum. A caller trying expanded and then legacy may incur both mode costs. Per-pass caps remain gridCells20,000, supportedNodes20,000, layers32, entries48 legacy/192 expanded, edges80,000, candidateRoutes4,096, topologyQueries160,000, approachBuilds8, indexReferences24,000,000. Returned counters alone are not the summed work; nested and outer pass-complete trace records are the evidence for total cost.
