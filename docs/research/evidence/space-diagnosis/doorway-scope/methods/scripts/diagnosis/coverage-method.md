# Fair route scheduling correction

This separately frozen retrospective correction follows measured search censoring in completed baseline and entry-prism traces. The diagnosis is `.runtime/space-diagnosis/coverage-diagnosis.md`: in an unresolved doorway case, seven entry-rooted searches consumed4,096 candidate evaluations while148 selected entries remained unscreened. Six complete traversals repeatedly visited the same1,602-node component. This demonstrates an ordering limitation; it does not establish a valid missed route. No cohort evaluation occurs before this method's freeze.

## Scope and preservation

`routes-coverage.ts` exports `assessDiagnosedSpace` with the unchanged input/output seam. It first calls the entire frozen `routes-entry.ts` assessor for the requested mode, preserving both its original baseline-first behavior and successful prism paths. A successful predecessor assessment is returned unchanged. Only a failed same-mode predecessor runs one additional bounded fair scheduling pass. The outer selected-scale expanded→legacy harness remains owned by the lead. Original and entry-phase files, original navigator, source triangles, player, criteria, witnesses and selector stay unchanged.

The fair pass copies the entry method. Its proposal population, ranking and selected192expanded/48legacy entries are identical. It applies the same original-contact and full support/body prism proof to every selected proposal before allocating route witness work. No new proposal is introduced; immediate-neighbor exclusions and ranking-cap losses are deliberately retained. No topology threshold, local-width interpretation or semantic clause is changed.

## Deterministic candidate quanta

Every admitted entry gets a resumable BFS with the predecessor's exact neighbor order, supported-node identities, visited semantics, endpoint displacement/parity rule and reconstructed shortest paths. Entries advance in original rank order. A stream yields at most one eligible candidate per round; its witness evaluation runs atomically using the original cached features and global ray wrapper, then the next entry advances. A stream with no remaining endpoints retires. A qualifying witness still requires unchanged complete forward/reverse navigation from the actual bounds-exterior approach start; as before, the entry retires after its first qualifying witness's seam attempt even if that seam fails.

Distinct entries into the same component remain separate: entry-rooted paths can have different required witnesses. This correction does not deduplicate components or skip a route because nearby paths failed. Cached edge and feature records remain single observations per key. Globally interleaving cached discoveries can change when shared caps are encountered; that is part of the measured scheduling effect, not a completeness claim.

The global4,096candidate/160,000ray/80,000edge/8approach-build limits remain unchanged. Candidate counters now count executed candidates only, so the fair pass stops at4,096 rather than recording a4,097th unevaluated candidate as older diagnostics do. Once the route, ray or approach-build budget stops the pass, remaining streams are logged as unexecuted. A witness that exhausts the ray cap fails closed through the original final budget guard; the scheduler never resumes another witness after that exhaustion. No extra rays are used to choose the next stream. A single expensive witness can still consume the remaining global ray budget.

## Memory, work and trace attribution

BFS predecessor and queue arrays are compact Int32 arrays allocated lazily as each generator first advances. They hold at most20,000nodes per selected entry: at most192×20,000×2×4=30,720,000bytes expanded (7,680,000legacy), plus the existing mesh/index/cache and small generator records. Each entry visits any node at most once, so total BFS visits remain bounded by selected entries times supported nodes. Screening all selected entries adds bounded work before the first witness. The full wrapper can run three bounded passes per mode (original,prism,fair) or six across outer expanded/legacy fallback; returned metrics describe only the selected pass, not aggregate work.

Trace wrappers emit `coverage-pass-start/complete`, tag nested events `pass: predecessor | coverage-round-robin`, and retain the predecessor's original `baseline | entry-prism` tag as `predecessorPass`. The fair scheduler emits `stream-admitted`, `scheduler-start`, `stream-resumed`, `candidate` with round/localCandidateIndex, `stream-suspended`, `stream-complete`, `stream-unexecuted` and `scheduler-complete`. Resource metadata includes admitted count, maximum compact state bytes, original budgets and stop reason. Observations are cloned; sink errors propagate. No sampling or silent truncation is introduced.

## Synthetic validation and limitations

Tests require a large early uncovered component to exhaust sequential route checks while a later selected covered hall is reached by fair scheduling, with the exact selected proposal list and shared per-entry first BFS paths preserved. They verify unchanged successful predecessor assessment in both modes, original-only generated support and reversible movement, multiple streams retained in one component, deterministic one-candidate-per-stream-per-round scheduling, unique cached feature observations, fail-closed route/grid/unsupported-intent limits, and retained sealed-room/internal-hole/thin-barrier/disconnected-support rejection.

The method remains censored by proposal population, ranking, shared budgets and single BFS path per endpoint. It may trade depth in an early promising entry for breadth among many unproductive entries; preserving predecessor success prevents a same-mode verdict regression from that trade. It does not guarantee an interior exists or resolve geometry intent. Freeze hashes must include this method plus routes-coverage.ts and all predecessor/navigator/criteria dependencies. Full cohort comparison and original browser movement verification belong to the lead after freeze; a recovered geometry verdict alone is not a browser success.
