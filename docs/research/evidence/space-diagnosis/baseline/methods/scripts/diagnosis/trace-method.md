# Acceptance-preserving route trace

`routes-traced.ts` is an observational copy of the frozen `scripts/interpretation/routes.ts`. `assessDiagnosedSpace` accepts the same mesh, transform, criteria and search mode, plus optional `trace: TraceSink`, and returns the same assessment shape. No physical, geometric, support, enclosure, topology, search or budget rule is changed. The original source remains unchanged. The caller binds the stream to source hash, compiler criteria, method hashes and prior attempt, and supplies monotonic stream sequence numbers and durable storage.

All navigator calls and spatial-index queries occur in their original order. Tracing consumes existing results; it does not run alternative routes, evaluate skipped predicates, extend budgets, resample geometry or clear obstacles. A source triangle's coordinates may be read by ID for a trace, which performs no spatial query. Cached edge/feature/broad-region observations are emitted once, with stable references from later route checks. Copying observations with `structuredClone` before handing them to the sink prevents ordinary mutation of an emitted object from altering acceptance state. A malicious sink modifying separately captured input arrays is outside the passive-sink contract.

The module neither accumulates all events nor samples/truncates them. Every emitted event is passed synchronously to the sink. Sink exceptions propagate, aborting the assessment; the harness must mark the trace incomplete rather than accept a partial stream. Input/index validation exceptions also propagate as before; an absent `assessment-complete` is an incomplete/exceptional run, not an accepted diagnostic result. Timing measurements include observational overhead and are the only result fields expected to differ.

## Stable references and event families

Node IDs are original grid insertion indices. Proposal IDs are `nodeId:directionIndex`, with direction order −X,+X,−Z,+Z. Ranking never modifies these IDs. Route IDs are the original candidate-route counter. Source triangle IDs always refer to unchanged source mesh indices. Broad feature keys are `nodeId:open`, `nodeId:covered` or `nodeId:support`.

| Stage | Main kinds and observations |
|---|---|
| support | `grid` gives dimensions/bounds/cap; `column` records all existing floor hits, including empty columns; `rejected` keeps full support rejection including body triangle where available; `node` records full accepted support; `duplicate-layer` records deduplication; `accepted-dense-sample` records final unchanged dense proof. |
| proposal | `eligible` records raster position; `direction-excluded` records AABB distance or same-layer neighbor exclusion; `legacy-body-sample` records original body probes; `direction-unexecuted` marks directions skipped after legacy's first success. `rank-selection`, `selected` and `omitted` give rank/policy/score or entry-cap omission; `attempt` and `not-attempted` distinguish retained proposals actually searched from those skipped after success or budget/criteria termination. |
| prescreen | `edge-support-probe` records every existing outward scan, bisection and final contact query; `support-edge-not-found` / `edge-contact-missing` identify early stops. `projection-start` gives seam, exterior corridor and contact; `projection-blocked` gives the first original triangle and clipped polygon in approach coordinates. `body-sample` gives original collision ID/triangle/position. `rejected` records first failure and unexecuted later stages; `passed` means prescreen only, not verified seam movement. |
| component | `entry-search` reports whether the entry node had previously been reached and the existing component counter; `node-discovered` gives predecessor/queue index; `node-visited` gives endpoint displacement and checkerboard eligibility. This remains reached-entry exploration, not exhaustive mesh decomposition. |
| edge | `tested` appears once per uncached tested edge with original height threshold and forward/reverse movement results. Height rejection records movements as unexecuted. A cached result is referenced through stable node/edge IDs without duplicating its evidence. |
| route | `candidate` gives the full original predecessor path; `candidate-not-executed` records the original counter's over-cap endpoint. `accepted` / `seam-rejected` record the actual final decision and that this entry search stops at its first qualifying witness, even if that seam fails. |
| topology | `ray` records every existing ray, range, hit ID and point; `ray-not-executed` records budget censoring. `node-feature` and `broad-feature` emit cached evidence once. `node-predicate` lists passed, failed and not-evaluated short-circuit checks with measurements and thresholds. `sustained-sample` / `sustained-result` record contiguous witness distance and unexecuted suffix after success. Aperture/deck events preserve their axis, ray, support, signed-crossing and width/elevation checks. `witness`, `route-rejected`, and `route-qualified` identify completed, first failing and unexecuted topology requirements. |
| seam | `swept-forward` and `swept-reverse` retain both original move results, start/target, endpoint error and threshold. Both calls execute in the frozen implementation even when forward fails. |
| budget | `exhausted` emits the first observation of each original cap, with the then-current counters; `index-reference-limit` records the original index construction exception. |
| result | `assessment-start` binds input transform/criteria/mode/budgets; `assessment-complete` includes unchanged status, reasons, counters, final selected IDs and dense sample count. |

Expanded ranking scores reflect each proposal's last *executed* update of its minimum distance to previously selected entries, including the original direction offset. They are not recomputed after the last selection or for omitted entries. Infinite initial scores are explicitly encoded as `"Infinity"`. Legacy ranking uses raster spread and has no geometric score. An omitted proposal is censored by a cap, not demonstrated invalid.

For sustained topology tests, a route can have many failing node predicates before later qualifying. `route-rejected.firstFailingTopology` means the first required topology whose route search failed; it does not mean every route node failed that same elementary predicate. `node-predicate.firstFailure` identifies the first executed elementary failure at that node. `not-evaluated` deliberately contains no fabricated measurement from an additional geometry query. Bridge checks retain the original non-short-circuit behavior: later edge/void probes still execute after an elevation failure, and their observed failures are distinguished from the first one. Aperture widening retains `.every` short-circuiting, so the second side is explicitly unexecuted if the first side fails.

The unchanged navigator reports a reason but does not expose the blocking triangle for every swept-body or projected-support failure. Such seam/edge traces retain the returned reason and available support IDs; no extra query is performed to invent a missing blocker ID. Trace-based attribution must respect that limitation.

## Synthetic parity gate

`npx tsx --test scripts/diagnosis/routes-traced.test.ts` compares the entire original and traced assessment after zeroing only `metrics.buildMs` and `metrics.assessmentMs`. It covers both search modes; accepted enclosure, courtyard, aperture, bridge and tall broad interior; absent coverage; sealed walls; a large internal hole; proposal caps; grid caps; unsupported criteria; and a tapered seam whose existing forward/reverse movement rejects the crossing. Tests also check that emitted edge/ray counts equal original counters, cached evidence is not duplicated, short-circuited predicates remain unexecuted, proposal dispositions partition the original proposals, streamed sink failures propagate, and emitted-object mutation cannot alter the assessment.

Typecheck before integration. The lead runs full repository verification and then source/hash-bound selected-scale replay against historical corrected attempts, comparing all acceptance fields except timings and external provenance. Any parity mismatch invalidates the observational baseline until understood; do not classify it as a recovered case. No cohort run or targeted acceptance correction was performed while implementing this trace module.
